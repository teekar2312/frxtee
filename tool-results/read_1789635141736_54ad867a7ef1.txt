   641→   641→[F-01] CRITICAL — No authentication on any API route (real-money trading)
   642→   642→  File: python-backend/main.py (all routes), python-backend/config.py:44
   643→   643→  Problem: Zero auth on FastAPI app. POST /api/trading/order places a real forex

   650→   650→    account, open max-leverage positions, or trigger account-killing drawdowns.

   652→   652→    (order, connect, close, alerts, email/test, ml/train). Require a shared

   657→   657→[F-02] CRITICAL — Daily risk limit is dead code; register_loss() never called
   658→   658→  File: python-backend/risk_manager.py:69 (declared), python-backend/main.py (never invoked)
   659→   659→  Problem: `RiskGuard.daily_loss` only increments via `register_loss(amount)`.
   660→   660→    Grep across the entire backend confirms: `register_loss` is declared but
   661→   661→    NEVER called anywhere — not from `api_close` (main.py:162-167), not from a

   666→   666→    A bad AI signal loop or a manual mistake can lose 100% of equity; the

   759→   759→  Problem: The order route IS `async def` and contains no `await` between
